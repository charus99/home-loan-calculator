# Home Loan Calculator

เครื่องคำนวณสินเชื่อบ้านตามกติกาไทย — ดอกเบี้ยลดต้นรายวัน ดอกเบี้ยขั้นบันได
และการเปรียบเทียบข้อเสนอรีไฟแนนซ์

**สถานะ:** กำลังพัฒนา — ตรรกะการคำนวณเสร็จแล้ว หน้าจอยังเป็นตัวอย่าง

## คำถามที่แอปนี้ตอบ

- ผ่อนเดือนละเท่าไหร่ ตลอดสัญญาจ่ายจริงเท่าไหร่
- ควรรีไฟแนนซ์ไหม คุ้มกับค่าใช้จ่ายหรือเปล่า
- ถ้าโปะเพิ่มเดือนละ X ประหยัดดอกเบี้ยเท่าไหร่ หมดหนี้เร็วขึ้นแค่ไหน
- ข้อเสนอของธนาคารไหนคุ้มกว่า

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

| คำสั่ง | ทำอะไร |
|---|---|
| `npm run dev` | รัน dev server |
| `npm test` | รัน test ทั้งหมด |
| `npm run test:watch` | รัน test แบบ watch |
| `npm run build` | ตรวจ type แล้ว build |
| `npm run lint` | ตรวจโค้ดด้วย oxlint |

## โครงสร้าง

```
src/
  core/    ตรรกะการเงินล้วน — TypeScript ไม่ import React
  ui/      React component และการจัดรูปแบบตัวเลข
docs/      requirement และการตัดสินใจเรื่อง tech stack
```

`src/core` ห้าม import React หรือแตะ DOM เพื่อให้ทดสอบสูตรได้โดยไม่ต้องเรนเดอร์
และเปลี่ยนวิธีจัดการตัวเลขภายหลังได้โดยไม่กระทบหน้าจอ
